# CodeExam Secure - Legitimate Program Corpus

This directory contains programming problems, reference solutions,
and 30 legitimate sample programs for testing the CodeExam Secure prototype.

## Problems

### 1. sum_numbers
- Reads an integer n followed by n integers.
- Prints the sum of those integers.
- Contains 10 sample programs.

### 2. reverse_text
- Reads a line of text.
- Prints the text in reverse order.
- Contains 10 sample programs.

### 3. count_primes
- Reads an integer n.
- Counts prime numbers less than or equal to n.
- Contains 10 sample programs.

## Directory structure

- problems/: Problem descriptions, test cases, and reference solutions.
- legit_programs/: Legitimate sample programs grouped by problem.

## Sample programs

There are 30 sample programs:
- 22 Python programs (.py)
- 8 C++ programs (.cpp)

## Testing

All 30 sample programs were tested against the five test cases
for their respective problems.

Total tests: 150
Passed: 150
Failed: 0

All 30 programs passed all tests.
